# Sources matérielles flow.io

Les fichiers nécessaires à la fabrication du matériel flow.io sont classés par sous-ensemble.

- [`catalog.yaml`](catalog.yaml) décrit les versions, les fichiers et leurs empreintes SHA-256.
- [`bom/`](bom/) contient les nomenclatures normalisées.
- [`companion/v1.1/`](companion/v1.1/) contient la source EasyEDA, les Gerber et le modèle 3D de la Companion v1.1.
- [`companion/facade/`](companion/facade/) contient la façade de boîtier DIN.
- [`led-panel/`](led-panel/) contient la source EasyEDA du panneau frontal de LEDs.

Les guides de montage et de raccordement se trouvent dans [`docs/hardware/`](../docs/hardware/README.md).
